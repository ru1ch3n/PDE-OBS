## Definitions

For a declared destination set W: `mean_mix = mean_w E_mix,w`, `mean_specialist = mean_w E_w,w`,
`geomean_ratio = exp(mean_w log(E_mix,w / E_w,w))`, all over the same W. `E` is the strict joint relative L2, float64
per identity then the arithmetic mean over the 200 held-out identities. Transfer statistics are descriptive (the eight
specialists trained on other views, tested on w). Decomposition and projection are defined in
`tools/revision/static_diagnostics.py`; bootstrap statistics in `tools/revision/bootstrap.py`.

  Transolver matched blocks 0.96 (share 0.04).
